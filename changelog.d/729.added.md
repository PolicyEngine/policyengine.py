Added `policyengine.provenance.supported_years(country_id, dataset_path)`, which returns the years the installed country model supports a single-year dataset for: the years its `extend_single_year_dataset` projects the file to, built as the model's own `Simulation` builds them and without running any formula, from the data year onwards. The UK runs to policyengine-uk's default projection end (2024–2032 for a 2024–25 dataset on policyengine-uk 2.151.0). The US runs to the earlier of policyengine-us's default projection end and the last year of spm-calculator's SPM forecast, and `US_EARLY_YEAR_ALLOWANCE` keeps 2022 and 2023 supported for now (2022–2035 for `populace_us_2024` on policyengine-us 2.2.1 and spm-calculator 1.0.0). The UK qualification check and execution receipts now use this function rather than their own copies of the rule. Added `UnsupportedDatasetYearError`, a `ValueError` whose message and `country_id`, `dataset`, `years` and `supported_years` attributes name the refused years, the country and the supported years.
