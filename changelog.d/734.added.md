The bundle manifest now records each certified dataset's supported years, on `data_releases.<country>.certified_data_artifact.supported_years` (sorted ascending without duplicates): 2022–2035 for the certified `populace_us_2024` under policyengine-us 2.2.1, policyengine-core 3.33.3 and spm-calculator 1.0.0. Certification computes them on the certified file's bytes with exactly the certified model, core and (US) spm-calculator, in a separate `uv run --isolated` environment (`policyengine.provenance.dataset_years.supported_years_in_environment`), and `scripts/bundle.py record-supported-years --country <country>` records them for the current certificate without re-certifying. `scripts/bundle.py check` and `CertifiedDataArtifact` refuse a malformed record. `policyengine.provenance.dataset_years.recorded_supported_years(country_id, dataset=None)` returns the record for a dataset request. The UK record is not yet filled in.
