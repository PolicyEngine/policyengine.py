US `create_datasets` now writes each year file to a temporary file beside its path, re-checks the source, stamps the temporary file and moves it into place in one step (as UK year files already are). A year file's tables and stamp therefore always come from one cut, even when two processes cut the same year files at once, and a failed cut leaves the year files already there whole. The US year-file stamp now records the year the file was cut for (format revision 3), so a year file copied or renamed to another year's name is cut again rather than reused; year files stamped by earlier releases are cut again once.
