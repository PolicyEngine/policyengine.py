CI now fails a pull request whose head commit holds agent or job notes: a `.job/`, `.job-git/` or `.diag/` folder at any depth, or `HANDOFF.md`, `handoffs.jsonl`, `PR_BODY.md`, `PR-BODY.md`, `REPORT.md` or `PROGRESS.md` at the repository root. The new Agent notes workflow runs `.github/check-agent-notes.sh` on every pull request, which the code workflow's path filter would skip, and on main on every push and once a day, which `[skip ci]` cannot skip. `.gitignore` now ignores the three folders.
