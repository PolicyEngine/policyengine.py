CI now fails a pull request whose tree holds agent or job notes: a `.job/`, `.job-git/` or `.diag/` folder at any depth, or `HANDOFF.md`, `handoffs.jsonl`, `PR_BODY.md`, `PR-BODY.md`, `REPORT.md` or `PROGRESS.md` at the repository root. The new Agent notes workflow runs on every pull request, since the code workflow's path filter skips a pull request that adds only such files. `.gitignore` now ignores the three folders.
