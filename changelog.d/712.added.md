CI now fails a pull request whose head commit holds agent or job notes: a `.job/`, `.job-git/` or `.diag/` folder at any depth, or `HANDOFF.md`, `handoffs.jsonl`, `PR_BODY.md`, `PR-BODY.md`, `REPORT.md` or `PROGRESS.md` at the repository root. The new Agent notes workflow runs main's copy of `.github/check-agent-notes.sh` on every pull request, through `pull_request_target`, so neither the code workflow's path filter nor `[skip ci]` skips it, and it reads the head commit as data without running code from it. `.gitignore` now ignores the three folders.
