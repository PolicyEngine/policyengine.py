US year files now record the source dataset they were cut from and the policyengine-core and policyengine-us versions that cut them. `ensure_datasets` creates a year file again, and `load_datasets` refuses it, when the requested dataset now resolves to another source or another version is installed. A year file cut from a bundle dataset is tied to the revision and sha256 the bundle pins, so re-pinning a dataset under the same name (such as the ACS-local replacement) no longer reuses year files cut from the old release. A local source is identified by its path, size and modification time, and an explicit Hugging Face URI by the URI. Deciding still reads only each year file's stamp and renames record, and never downloads or reads the source. `create_datasets` stamps the year files only if the source file is still the one it materialized, and otherwise leaves them unstamped and raises `DatasetMaterializationError`. Requesting two different sources that share a name (and so would share year files) now raises `ValueError`.
