Add execution receipt schema v1 (`policyengine.provenance.receipt`), which records exactly what produced a result: the installed wrapper, model and core versions; the data release and the SHA-256 of the simulated dataset bytes; the certificate digest, attached only when the certificate covers that model and those bytes; reform and baseline digests; and the fiscal-year convention. Digests use RFC 8785 canonical JSON (`policyengine.provenance.canonical`), and the JSON Schema ships at `policyengine/data/schemas/execution_receipt.v1.schema.json`.
