Map the stored US WIC take-up draw `would_claim_wic` onto `takes_up_wic_if_eligible` when loading US data, so policyengine-us 2.x no longer gives WIC to every WIC-eligible person. `Simulation.run()`, `managed_microsimulation` and `create_datasets` apply the mapping and record the renames applied (output dataset metadata, `release_bundle`, saved output files, run records, `policyengine_bundle` and dataset metadata). A stored table that is not in the simulation's person order is refused. The mapping turns itself off once the data stores `takes_up_wic_if_eligible` or the engine defines `would_claim_wic` again. Saved US outputs from earlier releases are no longer loaded, so `ensure()` recomputes them. Year files written by `ensure_datasets` or `create_datasets` before this fix store neither name; delete and regenerate them.
